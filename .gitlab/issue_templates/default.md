## Issue type

When opening a new issue, please check the correct issue type, and verify its content according to the following rules:

- [ ] Bug
  - [ ] A clear description is provided
  - [ ] The steps to reproduced are documented
  - [ ] The expected behaviour is specified

- [ ] Feature Request
  - [ ] A clear description of the need and its value is provided
  - [ ] _If possible, a solution is proposed_

- [ ] Question
  - [ ] The question is clearly formulated

Any incomplete or unclear issue may be closed.
